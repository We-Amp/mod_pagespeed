`ShardDomain` was the one deprecation still produced as free text inside the domain code, so the lint could only show it as the generic PS110. It is now listed in the deprecated-option table next to the other retired options, and the lint reports it as PS202.

- The module warns exactly as before: same text (now built by one shared function, `DomainLawyer::ShardDeprecationMessage`), same timing (when the mapping is added), still once per distinct mapping per process. An empty shard list still warns nothing.
- The lint reports PS202 for every `ShardDomain` line with a list; the duplicate PS110 is suppressed. Values stay masked as for any option not on the safe list.
- New golden `32-deprecated-shard-domain`.

Tests (optimized build; `lint_golden_test`, `lint_secret_test` pass; the rewriter test binary filtered to the shard/deprecation tests, including `ShardDomainDeprecationWarning` and `ShardDeprecationWarning`, passes).
