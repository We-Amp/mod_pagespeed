Seasonal planting notes

These notes describe a small example garden at example.test. The text is synthetic and exists only so that a Markdown copy of the page has headings, paragraphs, lists, links and a table to carry.

Spring

  • Sow peas and broad beans once the soil can be worked.
  • Divide perennials that have grown too large for their bed.
  • Start tomatoes indoors six to eight weeks before the last frost.

Summer

  1. Water deeply in the early morning.
  2. Mulch beds to keep moisture in the soil.
  3. Pick beans often so the plants keep producing.

Autumn

Plant spring bulbs, collect seed from open-pollinated varieties and add fallen leaves to the compost heap. A link to this page checks that relative links survive conversion.
