# Shared user-agent vectors for the known-agent classifier.
#
# Format
#   Lines starting with '#' are comments; blank lines are ignored.
#   "# token: <token>" comment lines list the table tokens the vectors are
#   checked against (the "token" field of every entry in the agent table,
#   website/src/data/ai-crawlers.json). The token runs to the end of the
#   line and may contain spaces.
#   Every other line is one vector: <expected class><TAB><user agent>.
#   The user agent is everything after the first TAB, verbatim, with no
#   trimming and no escapes. The literal "(empty)" stands for the empty
#   user agent (a request with an empty or missing User-Agent header).
#
# Matching rule
#   A table token matches a user agent when it occurs in it, compared
#   case-insensitively (ASCII), and both ends of the occurrence fall on a
#   token boundary. A boundary is the start or the end of the string, or
#   one of the characters: space ( ) ; /
#   A token that contains a space matches as one phrase: the whole phrase,
#   with its single spaces, must occur, and only its two ends are checked.
#   Characters inside a token ('-', '.', '/', '_') are literal. There is no
#   substring match, no glob and no regular expression.
#
# Classes
#   3  a table token matches the user agent
#   0  no table token matches (unknown)
#   Class 1 comes from a signature verifier, never from the user agent, and
#   class 2 is never produced, so no vector expects either.
#
