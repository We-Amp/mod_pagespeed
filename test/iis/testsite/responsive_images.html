Responsive Images Test

This page tests the responsive_images filter which adds srcset attributes.

Thumbnail Image (256x192 display size)

An 1023x766 image displayed in a 256x192 thumbnail. PageSpeed will resize it and also serve with a srcset for other sizes.

Full Size Image (1023x766 - no scaling)

An 1023x766 image displayed at full size. PageSpeed may recompress it, but will not add a srcset.

Two-thirds Scale Image (682x511 display size)

An 1023x766 image displayed at 682x511 (2/3 scale). PageSpeed will resize it and also serve a 1.5x version in srcset.

Small PNG Image

A 65x70 image displayed at 10x10. PageSpeed will resize it and add a srcset for other sizes.

Image with data-pagespeed-no-transform

An image with data-pagespeed-no-transform. PageSpeed will not transform this file.
