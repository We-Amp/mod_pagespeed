# ThreadSanitizer suppressions for mod_pagespeed
#
# ProxyFetch has a known benign race on shared response headers protobuf.
# The fetcher thread's wrapper chain (CachePutFetch::HandleDone) reads
# status_code() while the sequence thread writes new headers via
# HandleHeadersComplete on the base fetch. The race is at the protobuf
# internal byte level (different logical fields, same message). The
# status_code value is never modified concurrently.
race:AsyncExpectStringAsyncFetch::HandleHeadersComplete
race:CachePutFetch::HandleDone

# APR allocator_alloc() reads allocator->max_index without the allocator
# mutex as a fast-path hint, then re-reads it under the lock before walking
# the free list. A stale hint only costs a missed node reuse. Benign by
# design upstream (still present on apr 1.7.x and trunk).
race:allocator_alloc
