# nginx ASan process-lifecycle stress rig

Runs the ASan-instrumented `ngx_pagespeed_module.so` inside a real nginx under
load, while repeatedly reloading (`-s reload`) and hard-restarting workers, then
sweeps for AddressSanitizer reports and crashes. Companion to the IIS rig
(`../iis/`); driven nightly by the nginx ASan lane.

## Key mechanics

- The nginx **binary is stock** (`--with-compat`, no sanitizer). All ASan coverage
  comes from the **module** (bazel `--config=clang-asan`) plus the clang ASan
  runtime **LD_PRELOADed** at start (`run-nginx.sh`). `ASAN_OPTIONS` sets
  `detect_leaks=0` (the server has intentional at-exit leaks — LSan stays on for
  unit tests), `exitcode=66`, and `log_path=<rig>/logs/asan`.
- Self-contained in `RIG_DIR` (its own nginx prefix) — no shared-infra mutation,
  so no snapshot/restore (unlike the IIS rig's `PageSpeedModule` swap).
- Corpus generated by the harness (`stress_shutdown.py gen-corpus`).
- **Gate:** `sweep_nginx_asan_rig.sh` exits non-zero on the harness rc, any
  `<rig>/logs/asan.*` report, sanitizer/crash tokens in `error.log`, or a core.

## Scripts

| Script | Role |
|---|---|
| `setup_nginx_asan_rig.sh` | Assemble the rig (nginx binary + ASan module + mime.types + corpus + conf + LD_PRELOAD/reload/restart wrappers) |
| `run_nginx_asan_rig.sh` | Start nginx, health-check, drive `stress_shutdown.py --server nginx` with reload/restart chaos |
| `sweep_nginx_asan_rig.sh` | Adjudicate ASan reports / error.log tokens / cores — **exit 1 on any hit** |

Env knobs (all have defaults): `RIG_DIR`, `NGINX_BINARY`, `MODULE_SO`,
`ASAN_RUNTIME`, `PORT` (18081), `DURATION`, `CONCURRENCY`, `REPO_DIR`.

## Build the module

```sh
bazelisk build --config=clang-asan --repo_env=NGINX_PATH=$HOME/nginx-src \
  //pagespeed/nginx:ngx_pagespeed_module.so
```
Use `~/.local/bin/bazelisk` on a non-interactive WSL2 shell; **not**
`--config=vendored` in a fresh checkout (cyclone comes via git_repository + the
CI remote cache).
