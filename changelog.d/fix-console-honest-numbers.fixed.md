- **The admin console states what its numbers measure.** Savings headlines on the Overview, Savings and Optimizer pages now say they are measured in transfer bytes and include compression. Warning counts say how far back the retained log really reaches when it is younger than 15 minutes. Chart time axes no longer repeat a label, the Graphs page opens on the narrowest range that has history and shows how often history is logged, a share with no requests reads "—" instead of 0%, and the Savings page labels module counters and optimizer counters separately. The admin JSON now reports the host name without a trailing ":0" when the server has no explicit port.
