- **Admin console layout and accessibility.** The Histograms table scrolls inside its frame instead of widening the page, and its tables, the Configuration text and the Caches, Statistics and Optimizer pages are named, keyboard-focusable regions with unique names (the JavaScript and Memcached counter families are no longer listed twice). Long counter lists start collapsed, apart from the key counters, and a search opens the matching families. Backend statistics print sizes as MB and each path once, and say which counters they show. Savings figures keep their unit on one line, the Optimizer status row headers match their rows, and its version reads like the module's ("v2.6.0").
