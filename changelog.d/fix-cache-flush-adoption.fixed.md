- **After a cache flush through `cache.flush`, every server process serves the flushed state.** A server process that received few requests could keep serving cache entries from before the flush, and with several virtual hosts a flush of one host could be applied by some processes of another host and not by others, so a page could switch between results (for example between deferred and render-blocking stylesheets) depending on which process served it. Affects 2.8.0 and earlier.
