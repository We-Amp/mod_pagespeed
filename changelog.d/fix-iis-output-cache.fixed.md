- IIS: an HTML page that the module leaves unoptimized for an AJAX request is no longer kept in IIS's own response caches (the HTTP.sys kernel cache and the output cache). Before, a few AJAX requests for a page could make IIS hand the unoptimized copy to every later visitor of that URL, without the module, until the file changed.
- IIS: the module now optimizes requests that arrive over IPv6 with an IPv6 address as the host (for example `http://[::1]/`) on the default ports. Before, such requests were served unoptimized and the admin pages answered 404, and some IPv6 addresses were read as a different address.
