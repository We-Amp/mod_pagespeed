- IIS: `pagespeed RemoteConfigurationUrl <url>` in `pagespeed.config` now takes effect. Before, the line was silently ignored and only the form without the `pagespeed` prefix worked. **If your configuration already contains this line, the module now fetches and applies that remote configuration**: requests may wait up to `RemoteConfigurationTimeoutMs` (default 1 second) while it is fetched or refreshed, and if the fetch fails the local configuration (or the last good remote copy) is used. Remove the line if you do not want remote configuration.
- IIS: `UsePerVHostStatistics` and `CreateSharedMemoryMetadataCache` are not supported on IIS; setting either now logs a warning at configuration load that it has no effect, instead of being accepted silently. Invalid values are still rejected.
