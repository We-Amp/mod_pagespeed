- **CSS rewriting keeps class names that start with a digit.** Tailwind-style class names that start with a digit, such as the `2xl:` responsive utilities (written `.\32 xl\:p-4` in the stylesheet), were broken by CSS rewriting: the escape for the leading digit was dropped, so those rules no longer matched their elements. Such names, and names that start with `-` and a digit, now keep a valid escape.
