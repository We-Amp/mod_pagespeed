Added: C API 1.13 can keep a front end's pages in one site's keyspace. `ps_cache_write_headers_sidecar_site` stores a headers sidecar paired with the stored original, `ps_headers_sidecar_read` reads it back with its pairing, `ps_cache_remove_site` removes a page's entries in one site, and `ps_cache_write_site_purge_epoch` and `ps_cache_read_site_purge_epoch` keep a per-site purge time that never moves backwards. `ps_write_params_t` gains `origin_html_hash`; callers built against older headers are unaffected.
