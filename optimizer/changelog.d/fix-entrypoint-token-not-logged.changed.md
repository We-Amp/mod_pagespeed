Changed: the container images no longer print a generated `PAGESPEED_API_TOKEN` or `PAGESPEED_PURGE_TOKEN` to the container log. When you do not set them, the entrypoint writes the generated values to `/data/generated-tokens` (mode 0600, one `KEY=value` per line; the path follows `DATA_DIR`) and the log names that file and how to read it, for example `docker exec <container> cat /data/generated-tokens`. Tokens you set yourself are used as before, and no file is written for them.
