Make Google Analytics Asynchronous

Deprecated: this filter is now a no-op. It rewrote pages that loaded the synchronous Universal Analytics ga.js snippet to load it asynchronously instead. Universal Analytics was discontinued in July 2023, which made the synchronous ga.js snippet — and this rewrite — obsolete.

The filter name make_google_analytics_async is still accepted in configuration files for compatibility, but enabling it emits a warning and has no effect on pages. Remove it from your configuration, along with any remaining ga.js snippets on your pages.
